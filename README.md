# تطبيق تسبيح الذكر 📿

تطبيق **تسبيح الذكر** هو رفيقك اليومي لأداء الأذكار بكل سهولة وراحة.

## 🌟 مميزات التطبيق
- **تصميم هادئ:** واجهة مريحة للعين لتجربة تسبيح روحانية.
- **عداد دقيق:** حساب التسبيحات بدقة عالية.
- **خفيف وسريع:** لا يستهلك موارد الجهاز.
- **تحديثات مستمرة:** ميزات جديدة تُضاف دورياً.
