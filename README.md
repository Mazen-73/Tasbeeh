# تطبيق تسبيح 📿

تطبيق **تسبيح** هو رفيقك اليومي لأداء الأذكار بكل سهولة وراحة.

## 🌟 مميزات التطبيق
- **تصميم هادئ:** واجهة مريحة للعين material 3 expressive.
- **عداد دقيق:** سبحة بدقة عالية.
- **خفيف وسريع:** لا يستهلك موارد الجهاز.
- **تحديثات مستمرة:** ميزات جديدة تُضاف دورياً.
